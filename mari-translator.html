隐私政策 · 翻译娘MARI（KISS Translator fork）

适用于 Chrome 扩展「翻译娘MARI」（Transelle）。

我们收集哪些数据

扩展自身不收集、不存储、不中转你的任何个人信息。

翻译数据的去向

为实现翻译功能，待翻译的网页文本（以及漫画翻译时的图片）会由你的浏览器直接发往你在扩展设置中自行选择的翻译服务（例如 DeepSeek、Ollama，或任意 OpenAI 兼容服务），用于生成译文。是否发生传输、发往何处，完全由你决定。扩展不保留这些内容，也不向除你所选服务之外的任何第三方共享。

密钥与配置

你填写的 API Key、站点规则与语言偏好仅保存在本机浏览器存储中，不会上传到任何服务器。

我们不做什么

  • 不在后台收集你的浏览历史、位置或用户活动；
  • 不出售数据，不将数据用于与扩展核心功能无关的用途；
  • 不将数据用于信用评估或借贷用途。

权限说明

  • storage：保存引擎配置、API Key、站点规则与语言偏好。
  • scripting：向页面注入翻译脚本、渲染译文与漫画嵌字。
  • tts：朗读译文（可选功能）。
  • contextMenus：提供右键菜单入口。
  • declarativeNetRequest：按用户自配规则调整请求，用于代理读取跨域图片。
  • <all_urls>：网页翻译需在任意站点工作。

开源与署名

本扩展基于 KISS Translator（GPLv3）二次开发，遵循 GPLv3 许可并保留上游署名。
